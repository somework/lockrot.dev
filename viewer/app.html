How reports are made

Open a report someone sent you

A lockrot report is a JSON document, or the single-file page --format=html writes. Drop either one here and it renders the same way it would on the machine that produced it.

What you paste or drop stays in this tab. It is not uploaded, stored or logged — the rendering happens in your browser, in a sandbox that is not allowed to reach the network at all. A link of the form #url= is the one exception: that document is fetched, by your browser, from the host the link names, and only after you say so.

What produced this

lockrot reads a composer.lock and says which dependencies have stopped moving: a package whose last release is years old, one whose branch was left behind, one pinned to a version nobody ships any more. It reads release dates and repository activity and shows the dates it decided on, so every verdict can be argued with.
